# Contributing

Target this fork's `main`. Include the failing input or corrected source, the
expected behavior and a regression test. For a provider change, cover missing keys
and unreachable services as well as success. For a planning rule, explain how a
caller can verify it with the relevant authority.

Follow [AGENTS.md](AGENTS.md), run the [development checks](DEVELOPMENT.md) and
summarize the results in the pull request. Please follow the [code of conduct](CODE_OF_CONDUCT.md).
Contributions are covered by the [MIT license](LICENSE).
